# BUG-008: No PATCH endpoints to enable/disable sources or targets

## Status: CLOSED — FIXED (2026-04-02)

`PATCH /sources/{source_id}` and `PATCH /targets/{target_id}` are now implemented in
`main.py`. Both accept `{"enabled": bool, "notes": str | null}` and require the
`Authorization: Bearer <token>` header when `ADMIN_TOKEN` is set. `SourcePatch` and
`TargetPatch` schemas are in `schemas.py`.

**Note**: These endpoints are not yet covered by automated tests.

---

## Title
The API provides `POST /sources` and `GET /sources` but no `PATCH /sources/{id}` (or equivalent) to toggle `enabled` or update `notes`. Same gap for targets. The operator UI requires toggling sources and targets on/off without deleting history.

## Environment
- `app/main.py` — missing PATCH routes
- `docs/DESIGN.md` §"Sources / Targets list" — "Row disabled | Muted row, toggle off"
- `docs/DESIGN.md` §"Flow A: Configure sources and targets" — "Admin enables/disables sources"

## Steps to Reproduce
1. POST `/sources` to create a source with `enabled: true`.
2. PATCH `/sources/1` with `{"enabled": false}` to disable it.

## Expected
`200` response with the updated source object; subsequent collect runs skip this source.

## Actual
`405 Method Not Allowed` — no PATCH route exists.

## Impact
Without PATCH, the operator cannot:
- Disable a source that is returning bad data.
- Re-enable a previously disabled source.
- Update notes on a source/target.

These are described as core operator actions in DESIGN.md. The UI toggle control has no backing API call.

## Severity / Priority
**Medium / P2** — core operator workflow is blocked; the enabled/disabled flag is functional in `run_collect` but completely unreachable via the API.

## Fix Suggestion
Add partial-update endpoints:
```python
class SourcePatch(BaseModel):
    enabled: bool | None = None
    notes: str | None = Field(default=None, max_length=512)

@app.patch("/sources/{source_id}", response_model=SourceOut)
def patch_source(source_id: int, payload: SourcePatch, db: Session = Depends(get_db)):
    src = db.get(Source, source_id)
    if src is None:
        raise HTTPException(status_code=404, ...)
    if payload.enabled is not None:
        src.enabled = payload.enabled
    if payload.notes is not None:
        src.notes = payload.notes
    db.commit()
    db.refresh(src)
    return SourceOut(...)
```
Mirror for targets.
