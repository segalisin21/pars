# BUG-007: No list endpoints for collect-runs or invite-runs — operator UI cannot show history

## Status: CLOSED — FIXED (2026-04-02)

`GET /collect-runs` and `GET /invite-runs` are now implemented in `main.py`, returning
`{"items": [...]}` ordered by newest first. Schemas `CollectRunsList` and `InviteRunsList`
were added to `schemas.py`.

**Note**: These endpoints are not yet covered by automated tests.

---

## Title
`GET /collect-runs` and `GET /invite-runs` list endpoints do not exist. The operator UI pages `/collect` and `/invite` (DESIGN.md) must show "run history and metrics", but there is no way to retrieve the run list via the API.

## Environment
- `app/main.py` — missing routes
- `docs/REPORT.md` — documents only the singular `GET /collect-runs/{id}` and `GET /invite-runs/{id}`

## Steps to Reproduce
1. POST `/collect-runs` twice to create two runs.
2. GET `/collect-runs` — expect a list.

## Expected
```
GET /collect-runs  →  200  {"items": [{...run1...}, {...run2...}]}
GET /invite-runs   →  200  {"items": [{...run1...}, {...run2...}]}
```

## Actual
```
GET /collect-runs  →  405 Method Not Allowed
GET /invite-runs   →  405 Method Not Allowed
```
(FastAPI defaults to 405 for the unhandled GET on a route that only has POST.)

## Impact
Without list endpoints the operator UI cannot implement the run history page described in DESIGN.md. The operator has no way to retrieve past runs without knowing the exact ID.

## Severity / Priority
**Medium / P2** — blocks operator UI "run history" feature; API is functionally incomplete for v1 requirements.

## Fix Suggestion
Add to `main.py`:
```python
@app.get("/collect-runs", response_model=CollectRunsList)
def list_collect_runs(db: Session = Depends(get_db)):
    runs = db.scalars(select(CollectRun).order_by(CollectRun.id.desc())).all()
    return CollectRunsList(items=[CollectRunOut(...) for r in runs])

@app.get("/invite-runs", response_model=InviteRunsList)
def list_invite_runs(db: Session = Depends(get_db)):
    runs = db.scalars(select(InviteRun).order_by(InviteRun.id.desc())).all()
    return InviteRunsList(items=[InviteRunOut(...) for r in runs])
```
Add `CollectRunsList` and `InviteRunsList` schemas analogous to `SourcesList`.
