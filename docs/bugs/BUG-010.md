# BUG-010 — GET run detail endpoints lacked regression tests

**Severity:** Low (QA / coverage)  
**Status:** Resolved (2026-04-03)

## Summary

`GET /collect-runs/{id}` and `GET /invite-runs/{id}` were implemented and documented but not covered by pytest for 404 paths or workspace isolation.

## Resolution

- Added [`tests/test_run_detail.py`](../../tests/test_run_detail.py):
  - Unknown id → `404` with `collect_run_not_found` / `invite_run_not_found`
  - Wrong `X-Workspace-Id` → `404` (tenant scope)

## Verification

```bash
pytest tests/test_run_detail.py tests/ -v --tb=short
```
